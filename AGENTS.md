## PRINCIPLES

1. **First principles** — Start from the problem. Prefer the simplest thing that works.
2. **Code over docs** — If docs or anything else conflicts with the code, trust the code.
3. **Performance & UX first** — Prefer fast, smooth, user-friendly solutions.
